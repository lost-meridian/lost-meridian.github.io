GitHub 연결

게시 버튼을 누르면 저장소의 banners.json, news.json과 배너 이미지가 바뀌고, 1~2분 뒤 사이트에 반영됩니다.

  1. GitHub → Settings → Developer settings → Fine-grained tokens에서 새 토큰을 만듭니다.
  2. Repository access에서 이 저장소만 고르고, Contents 권한을 Read and write로 둡니다.
  3. 만든 토큰을 아래에 붙여 넣고 저장합니다. 토큰은 이 브라우저에만 저장됩니다.
